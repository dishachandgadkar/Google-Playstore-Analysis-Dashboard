# 📊 Google Play Store Analysis Dashboard

## 🚀 Project Overview
Developed an interactive Power BI dashboard to analyze Google Play Store application trends, ratings, installs, pricing patterns, and category-wise performance.

## 📌 Features
- Data Cleaning & ETL using Power Query
- KPI Cards & DAX Measures
- Paid vs Free App Analysis
- Category-wise Performance
- Ratings & Install Trends
- Interactive Slicers & Filters

## 🛠 Tools Used
- Power BI
- Power Query
- DAX
- Excel / CSV Dataset
